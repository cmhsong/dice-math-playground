# 🎲 주사위 수학 놀이터

주사위를 굴려 사칙연산 문제를 풀고, 모둠별 말판 놀이로 문제 대결을 하는 교실용 웹앱입니다.

## 기능
- **주사위 계산 놀이**: 주사위 2~6개, 덧셈·뺄셈·곱셈·나눗셈 선택, 문제 수 1~100개, 음수 허용 여부
  - 숫자 정하기: 굴린 주사위 눈을 학생이 세어 직접 입력(맞게 세야 식 완성) / 숫자 자동 표시
- **학습지 만들기**: 색깔 테마 5가지(보라·바다·숲·노을·흑백), 주사위 장식·자기 평가·선생님 확인 도장 칸, 주사위 그림·식 쓰기·숫자 식 3가지 모양, 글자 크기 80~200%, 한 줄 문제 수 자동(자동 줄바꾸기)·1~3단, 흑백/컬러, 이름 칸, 말판 문항 포함, 정답지 페이지, A4 인쇄·PDF 저장
- **말판 놀이**: 2~6모둠, 모둠별 인원수(1~12명)와 모둠원 이름 설정(모둠 안에서 돌아가며 굴리기), 문제 칸·계산 칸·앞으로/뒤로·한 번 쉬기·한 번 더 칸
- **말판·문항 편집**: 칸 수(6~60)와 칸 종류·이름 변경, 문항 추가·수정·삭제, 한꺼번에 추가, JSON 내보내기/불러오기
- **칭찬 목소리와 효과음**: 높은 톤에 문장을 또박또박 끊어 읽는 칭찬 음성(브라우저 음성 합성), Web Audio로 만든 효과음
- **글자 확대**: 화면 오른쪽 위 `가−` / `가+` 버튼(80%~200%)

설정은 브라우저(localStorage)에 저장됩니다.

## 사용한 오픈소스
- [3d-dice/dice-box-threejs](https://github.com/3d-dice/dice-box-threejs) (MIT License): 결과를 미리 정해 굴릴 수 있는 3D 물리 주사위. `vendor/dice-box-threejs/`에 원본 파일과 라이선스가 들어 있습니다.
